### ✨ Features

- 📖 **Calming Reading Background**: Soft milky page tone eliminates glare when reading long PDF books, papers, or documentation.
- 🎀 **Pastel Highlight & Annotations**: Sweet sakura pink highlighter (`#ffccd5`) and strawberry underlines (`#d44b8b`).
- 🌸 **Harmonious UI Controls**: Window frame, sidebar, and bookmarks tinted in soft rose tones.

---

### 📦 Setup Instructions

1. Open **SumatraPDF**.
2. Press `Ctrl+,` or go to **Settings** -> **Advanced Options**.
3. Open `SumatraPDF-settings.txt`.
4. Copy the settings from [`theme_settings.txt`](theme_settings.txt) and replace the corresponding sections.
5. Save the file and restart SumatraPDF!
